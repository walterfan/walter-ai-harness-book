# Harnessing AI / 驾驭工程 — book build dependencies (pip fallback)
#
# PRIMARY toolchain is Poetry (see book/pyproject.toml + book/poetry.lock):
#
#   make book-install     # poetry install into the book's own venv
#   make book-html        # sphinx-build en + zh_CN (strict)
#
# This file is the pip-compatible fallback for CI runners or contributors
# who don't have Poetry installed. It is regenerated from the Poetry lock
# by `make book-export-requirements` whenever poetry-plugin-export is
# available, so the two stay in sync.
#
# Install via pip:
#
#   python3 -m venv book/.venv
#   source book/.venv/bin/activate
#   pip install -r book/requirements-docs.txt
#
# All pins use the compatible-release cap (~=) so a dependabot bump does
# not silently move a major version.
