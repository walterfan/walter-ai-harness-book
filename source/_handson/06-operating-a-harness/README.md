# Hands-On · Ch.06 Operating a Harness

Two tracks:

- **Operating primitives** — generic scripts and templates teaching the
  four operating concerns (entropy, observability, approval gates,
  meta-evolution). Copyable into any repo.
- **Tauri-Todo worked arc** — a single end-to-end story that stitches
  the four concerns together using a real Tauri + Rust + TypeScript
  desktop-todo project.
