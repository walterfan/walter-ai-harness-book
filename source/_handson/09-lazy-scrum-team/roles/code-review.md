# Role: Code Reviewer

*Excerpted from the lazy-scrum-team skill's `roles/code-review.md`;
MIT-licensed; full definition in the skill repository.*

## Owns

- The `Hard vs Soft Gates` table for the repo.
- PR approval authority (except Final Acceptance sign-off).

## Produces

- Checklist comments against the Hard-gate list.
- Explicit waivers (role-signed, dated) for Soft-gate failures.

## Cannot

- Self-approve.
- Write the feature being reviewed.

## Hand-off contract

Dev → Code Review: PR opened with `hard-gates.md` section ticked.
Code Review → Dev: rework artefact is `bug-report.md` in the PR body.
