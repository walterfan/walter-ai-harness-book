# Hands-On · Ch.07 OpenHarness

Two files:

- `quickstart.sh` — clone the upstream
  [HKUDS/OpenHarness](https://github.com/HKUDS/OpenHarness) repo, install
  it into a fresh venv, and run a single verification session.
- `custom-tool.py` — a minimum-viable "Add a Custom Tool" example adapted
  from upstream `docs/tools.md` with attribution.

Both files are meant to be copied verbatim into a reader's own working
tree as the *smallest thing that works*.
