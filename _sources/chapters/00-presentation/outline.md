# Speaker Outline —— 分钟级节奏表

```{admonition} 使用方式
:class: tip

这一份是讲者的 **口袋小抄**，不是完整稿。每一个 7 分钟的段落列出：

- **目标**：这几分钟要让听众 *记住* 哪一件事。
- **钩子**：用什么话 / 什么图 / 什么反问把听众拉住。
- **可跳**：时间紧时可以砍的部分（delta 值是节省的分钟数）。
- **别讲**：**一定**不要陷进去的细节。
- **深一层**（可选）：如果气氛好、时间够，多讲一句反直觉的话。

所有内容都指向 `index.md`（可读稿）里的对应节。开讲前请至少通读一次
`index.md`，再把这份 outline 打印出来放在讲台上。

**术语约定**：`AGENTS.md / CLAUDE.md 兼容层 / SKILL.md / MCP / pre-commit /
Agent Loop / context / memory / tools / controller / Autonomy Envelope /
Bridle / Fence / Paddock / Groom / SDD / TDD / MDD / HarnessCard`
一律用英文。中文硬翻会丢细节。
```

## 总览（60 分钟）

| 段落 | 分钟 | 累计 | 节奏 |
|:--|:--:|:--:|:--|
| F.0 开场 —— M → E | 2 | 2 | 慢、画白板 |
| F.1 四阶段演化 | 7 | 9 | 论证、不急 |
| F.2 定义 + Agent Loop | 7 | 16 | 快念 5+5，loop 只画一圈 |
| F.3 三护法 SDD → TDD → MDD | 7 | 23 | 画因果翻转图 |
| F.4 3 × 4 矩阵 | 7 | 30 | **必画全表** |
| F.5 四个案例 | 7 | 37 | 每案一句话 |
| F.6 Lazy AI Coder 四幕 | 7 | 44 | 自证其身 |
| F.7 30 / 60 / 90 清单 | 7 | 51 | **高能收口** |
| F.8 Q&A 收尾 | 4 | 55 | 留给同事 |
| 缓冲 / 追问 | 5 | 60 | 任其自然 |

**排演过两轮以上再上台**。第一轮只讲稿（不开幻灯片也不画白板），
确认自己对 *流畅度* 有信心；第二轮完整跑一次，**一定**把 F.4 的矩阵
和 F.7 的三个里程碑用白板完整画一遍，记下两段分别花了多少分钟。

## 0:00 – 0:02 F.0 · 开场（2 分钟）

- **目标**：让听众 **立刻接受** 这一讲的中心比喻 —— *杠杆点从 M 移到了 E*。
- **钩子**：第一张 slide 只写 "Model → Environment"，停 5 秒；再开口讲。
- **可跳**：**不可跳**。这 2 分钟是全场的钩子。
- **别讲**：不要现在就讲 SDD / TDD / MDD 的内容，那是 F.3 的。
- **深一层**：三条 2026 事实念完之后可以加一句 —— *"注意：这三件事
  的共性是 —— 他们变的都不是模型，是模型周围的东西。"* 让听众自己
  把因果链闭合。

## 0:02 – 0:09 F.1 · 四阶段演化（7 分钟）

- **目标**：让听众记住 `Prompt → Context → Skill → Harness` 四个词的顺序，
  以及 **每一步都是被上一步的裂缝逼出来的**。
- **钩子**：画时间轴时故意停在 "Skill" 这一格，问一句 *"那 2026 以后呢？"*
  让听众接 "Harness"（大概率有人接得上）。
- **可跳**：如果超时，可砍掉"每阶段代表性制品"那一段，直接冲进
  "两句要带走的话"（**省 ~2 分钟**）。
- **别讲**：不要细讲 LangChain / Cursor / Claude 各自属于哪一阶段 ——
  F.5 会展开。
- **深一层**：加一句 —— *"前三阶段你可以一个人做；Harness 你必须以
  仓库为单位做。这是 2026 和 2024 最本质的差别。"*

## 0:09 – 0:16 F.2 · 定义（7 分钟）

- **目标**：让听众拿到 **一句话定义**、可用的 **归属检验**（commit 之前 / 之后），
  以及一张能定位跑偏原因的 **Agent Loop** 小图。
- **钩子**：把 "可验证 / 可观测 / 可理解" 竖着写在白板左栏，停 3 秒，
  再开口说 *"这三词不是修辞。"*
- **可跳**：五条"不是"里砍两条最末尾的（SDK 与部署流水线），听众
  自己能推出来（**省 ~1 分钟**）。
- **别讲**：不要纠缠 "Harness 和 AI Engineering 的关系"。一句话带过，
  抢时间。
- **深一层**：*"注意 'IS / IS NOT' 清单 5+5 里，'不是' 比 '是' 信息量
  更大。每一条 'IS NOT' 都堵住一个常见混淆。"*
- **穿插（可选，~3 分钟）**：`index.md` 里 F.2 末尾三段 —— **PDCA × Harness**、
  **规则 ／ 校验 ／ 恢复**、**Agent Loop**。时间紧则只画 **P→D→C→A**
  小环 + 念「D 快 C 慢必跑偏」一句；Agent Loop 只讲 **输入 → context →
  tools → observation** 这一圈，memory / controller / Autonomy Envelope
  细节指到第 03B 章。
- **深一层（少即是多）**：*"不要把整座图书馆塞进 context。LLM 知道很多，
  你要做的是收敛方向、立规矩、按总分总结构 progressive disclosure。"*
- **穿插钩子**：问 *"你们团队 PDCA 哪一格最薄？"* —— 十有八九是 **C** 或 **A**。

## 0:16 – 0:23 F.3 · 三护法（7 分钟）

- **目标**：让听众记住 **因果顺序反转** —— 从 `test → implement → observe`
  变成 `specify → test → observe`。
- **钩子**：上下对照那两行画出来之后，停 5 秒不说话，让听众自己
  读出 **"咦，SDD 顶到最前面去了"**。
- **可跳**：三护法各自一句的注释可以合并为 **三个单词 + 一个动词** 的
  快念（`SDD — 说 / TDD — 证 / MDD — 观`）（**省 ~1 分钟**）。
- **别讲**：不要展开 "书里有多少处对 SDD 的引用"，也不要辩论 SDD 和
  BDD 的差别 —— 附录 B 有，但这里不是场合。
- **深一层**：*"为什么翻转？ —— 因为人写的主要制品从代码移到了规约。
  这是 AI 辅助时代工程师劳动分工的最根本改变。"*
- **深一层（传统工程没有退场）**：*"AI 编程不是让软件工程失效，而是让
  老原则重新发光：小步提交、清楚 done、测试先行、可回滚、可追踪。"*
- **深一层（与 PDCA 接头）**：*"SDD ≈ 把 Plan 写清楚；TDD ≈ Check 自动化；
  MDD ≈ 让 Act 有证据 —— 三护法就是不让 D（智能体动笔）在真空里跑。"*

## 0:23 – 0:30 F.4 · 3 × 4 矩阵（7 分钟）

- **目标**：**让每个人离场时能背出四个英文词** —— Bridle / Fence /
  Paddock / Groom。这是全场最"骨头"的 7 分钟。
- **钩子**：**必须画全表**。不要用幻灯片 —— 一边画一边念。边画边说
  *"这张表就是剩下 30 分钟的地图，接下来所有东西都落回这 12 格。"*
- **可跳**：三个学术参考框架（CAR / Thoughtworks / LangChain）可以
  只留 CAR / HarnessCard 一行，其余两行一句话带过（**省 ~1 分钟**）。
- **别讲**：不要每一格都举例。听众记不住 12 个例子，记得住 4 个列
  + 3 个行 + 一句话归纳就够了。
- **深一层**：*"如果你家团队对这张表的反应是 '我们已经有了 8 格'，
  那问题不在缺的 4 格，在那 8 格里 **有几格是装饰、有几格是真正会
  拒绝坏工作的**。"*

## 0:30 – 0:37 F.5 · 四个案例（7 分钟）

- **目标**：让听众 **识别自己的项目最像哪一个案例**，从而有一个
  "抄作业对象"。
- **钩子**：画完横轴四个点后问一句 —— *"大家手里这个 repo，更像
  左边还是右边？"* 停两秒再继续。
- **可跳**：如果超时，砍掉 Claude Code 那一段（**省 ~2 分钟**），理由
  简单：它是唯一的闭源案例，不可直接抄作业。
- **别讲**：不要评价哪一份开源项目 "写得更好" —— 这一节目的是
  识别差异，不是打分。
- **深一层**：*"Superpowers 是 OpenHarness 的哲学反面 —— 一个只出
  技能不出运行时，另一个只出运行时不出具体技能。这两种极端都不是
  完整的马具。一个完整的马具，四列四列都得有人管。"*

## 0:37 – 0:44 F.6 · Lazy AI Coder 四幕（7 分钟）

- **目标**：让听众看到 **这套方法论对自己的宿主仓库也打分打得出来**。
- **钩子**：念出 "SDD 均值 1.75 → 3.00" 时刻意把 "1.75" 读慢、"3.00"
  读快 —— 听众会自动算出 delta。
- **可跳**：把 Act 2 五个短板中的 "MCP schema" 与"文档漂移" 两条合并
  （**省 ~1 分钟**）。
- **别讲**：不要展开讨论 `reproduce.sh` 的细节；**想演示就在现场敲**，
  不想演示就只放链接。
- **深一层**：*"MDD 那一行没动，是故意的。90 天内要先把 SDD 做到
  及格才配谈 MDD —— 先有规约才有可观察的内容。"*

## 0:44 – 0:51 F.7 · 30 / 60 / 90 清单（7 分钟）

- **目标**：**听众听完这一节离开前，每个人心里都有一格是 "我周一会动它的"**。
- **钩子**：画完三个里程碑后直接问一句 —— *"如果我们部门只做 Day 30
  这一步，你会选 SDD × Bridle 那格还是 TDD × Fence 那格？为什么？"*
  —— 这一问会让下一节 Q&A 自动热起来。
- **可跳**：如果时间紧，把"三条要提防的误读"一条一条砍；最值得保
  留的是 **"Day 30 我们就搞定了"陷阱**（**最多省 ~2 分钟**）。
- **别讲**：不要列具体 PR 数量；那是虚荣指标。强调 "delta + 证据指针"。
- **深一层**：*"本书最不想让你做的事情 —— **是先把 12 格全填齐再发布**。
  公开承认你只做完 1 格，比公开假装 12 格都在工作有价值得多。"*

## 0:51 – 0:55 F.8 · Q&A 收尾（4 分钟）

- **目标**：**把三句要被记住的话喊出去**，然后开 mic。
- **钩子**：把开场那张 M → E 图擦掉一半，只留 E，说 *"从今天起，
  先从环境开始。"*
- **可跳**：**不可跳**。这 4 分钟不是凑数。
- **别讲**：不要在 Q&A 环节介绍新概念 —— 同事问什么你答什么，
  有歧义就引到附录。
- **深一层**：如果有人问 *"我们部门没时间做这个"* —— 用这句话挡住：
  *"这问题本身是 MDD 的第一个信号。你没有的不是时间，是衡量
  '把马具装上能省多少返工' 的那张表。"*

## 0:55 – 1:00 缓冲 / 追问（5 分钟）

- **目标**：让想 **私下追问** 的同事有时间逮住讲者。
- **钩子**：不离场。把附录 C（阅读单）的链接贴到 Q&A 屏幕上不关机。
- **可跳**：这是缓冲，可以全砍给 Q&A 延续。
- **别讲**：不要新起一个话题。
- **深一层**：如果还有 3 分钟以上，问一句 *"有没有哪位愿意做
  Day 30 那格的主 owner？我们这周就拉一个 15 分钟立项会。"* —— 这一句
  能把分享会从 "听讲" 变成 "行动"。

## 应急切法

**30 分钟版**（半小时席间分享）：

1. F.0（2 分钟）
2. F.1（4 分钟，砍掉"代表性制品"段）
3. F.2（4 分钟，砍到只剩一句话定义 + 归属检验 + Agent Loop 一圈）
4. F.4（6 分钟，**完整画矩阵**，但每列一句话）
5. F.7（8 分钟，**完整讲三个里程碑**）
6. Q&A（6 分钟）

**90 分钟版**（工作坊）：

1. 照 60 分钟版跑完 F.0–F.7。
2. F.8 之前插入 25 分钟动手：**每人填一张 HarnessCard 的
   "SDD × Bridle" 格**，评分 0–5，证据写自家仓库里的 `AGENTS.md`
   或它的缺席。
3. 由志愿者读 3–5 份，集体讨论打分差异。
4. 回到 F.8 收尾。
